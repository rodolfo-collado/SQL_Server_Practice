# SQL Server Practice

Repositorio personal de prácticas con Microsoft SQL Server.

## Estructura

- `scripts/` → ejercicios y prácticas SQL
- `backup/` → archivos `.bak` de laboratorio
- `recovery/` → scripts de restauración y recuperación

## Entorno

- SQL Server 2025 (Developer Edition)
- Docker / Arch Linux
- DataGrip

## Objetivo

Documentar y versionar prácticas de bases de datos, incluyendo:
- usuarios, roles y permisos
- backups y restores
- esquemas y tablas
- mantenimiento y recuperación
